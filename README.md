# CyberTech Tronics Website

First static website version for CyberTech Tronics, designed for GitHub Pages.

## Files
- `index.html` — homepage
- `css/styles.css` — visual design and responsive layout
- `js/main.js` — mobile navigation

## GitHub Pages
1. Create a GitHub repository, for example `cybertech-tronics-site`.
2. Upload these files to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save.

GitHub will publish the site at the Pages URL shown in that screen.
